# AetherCodex 2.0.0

首个 AetherCodex 品牌版本。从 Codex++ 改名，补齐 Windows / macOS / Linux 三端打包。

## 安装

| 平台 | 产物 |
|---|---|
| Windows | `AetherCodex-2.0.0-setup.exe` |
| macOS (Apple Silicon) | `AetherCodex-2.0.0-macos-arm64.dmg` |
| macOS (Intel) | `AetherCodex-2.0.0-macos-x64.dmg` |
| Ubuntu 24.04+ / 26.04 / Debian 13+ (x64) | `AetherCodex-2.0.0-linux-x64.deb` |
| 同上 (arm64) | `AetherCodex-2.0.0-linux-arm64.deb` |

从旧的 `codex-plus-plus` 包升级可以直接装，deb 带 `Conflicts`/`Replaces`/`Provides`，会自动替换。数据目录改名并自动迁移，不需要手动搬。

**AetherCodex 不是 AI 客户端**，它是 Codex App 的外部启动器与管理工具，所以需要先装好 Codex App。装完后打开管理工具点「检查」，它会告诉你 Codex App 有没有被找到。

## 改了什么

### 改名与视觉
- 对外标识与内部 crate 全部改为 AetherCodex，数据目录改名并自动迁移
- 按 ARCHAI-CIVI-001 应用 Aether 视觉：直角几何、发丝分隔线，去掉装饰性阴影与渐变
- 单一母版图标流水线，CI 用 `--check` 守住产物与母版一致

### 启动时选择读哪份 Codex 配置
这是本版最重要的行为变化。

- **官方配置** `~/.codex` —— 你自己那份，官方 Codex App、shell 里的 `codex`、以及别的编排工具（比如 Orca）读的都是它。AetherCodex **全程只读**，中转注入在这个模式下关闭。
- **中转配置** `~/.aethercodex/codex-home` —— 通过 `CODEX_HOME` 隔离，注入只写这里。首次使用会从官方那份种一次 `auth.json`，免得落到登录页；之后两边凭据各自独立。

所有写入路径都会先检查当前 profile，官方配置下直接拒绝并说明原因，而不是悄悄改写 `~/.codex`。会话页和供应商页都带徽标标明当前读的是哪一份。

### 去掉的功能
- 推荐/广告位与赞赏码
- Discord 与 Telegram 入口

### 内置说明书
管理工具里新增「帮助」页，15 节离线手册，包含第一次使用、界面导览、官方/中转配置的区别、故障排查。版本号与代码不一致时 CI 会失败，所以它不会忘记更新。

### 维护性
- 上游 Codex++ 监测脚本与每日 workflow，产出可移植/新增/不采纳的分类报告
- Orca 联动设计文档（仅设计，本版不含实现）

## 修掉的问题

改名过程中踩到并修掉的四处真实破坏：

- 脚本市场和 Telegram 的外部 URL 被误改，会打不开
- Windows 卸载注册表项与快捷方式清理链被改断，旧版本残留清不掉
- 更新器按 `contains("plus")` 匹配产物，`AetherCodex-*.deb` 匹配不上，会认为没有新版本
- NSIS 里那些看起来像乱码的字符串其实是旧版真实落盘的文件名，改了就清理不掉

另外修了两个 IPv6 测试在无 IPv6 环境下的失败，以及一个断言依赖宿主机是否装过包的测试。
